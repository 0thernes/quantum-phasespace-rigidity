# Code of Conduct

This research repository adheres to professional academic and open-source discourse standards.

- Critique proofs, code, citations, and numerical claims rigorously and transparently.
- Focus feedback on mathematical correctness, reproducibility, and clarity — never on personal attacks.
- Maintain honest epistemic boundaries: distinguish machine-checked proofs, computational checks, and open conjectures clearly.
- Report conduct concerns to `0_0@0thernes.art`.
